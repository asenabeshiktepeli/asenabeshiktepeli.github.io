Automation case study

Python workflow with a human approval step

A personal system I built with an AI coding assistant to run my own remote job search: it collects listings, scores them, drafts tailored emails and waits for my approval before anything is sent. I can apply the same approach to repetitive business tasks such as order follow-ups or payment reminders. AI does the repetitive part; a person approves every result.

  1. 01 Collects job listings from multiple sources
  2. 02 Scores and filters them against my criteria
  3. 03 Checks ATS compatibility
  4. 04 Drafts a tailored cover letter for each listing
  5. 05 Tracks every application in a SQLite database
  6. 06 Prepares email drafts and waits for my approval before sending

Highlights

  • 500+ automated tests
  • Version-controlled with Git
  • No email is sent without my approval
